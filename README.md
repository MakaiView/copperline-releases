# Copperline downloads

Copperline is a macOS app for decorative copper name artwork, by Makai View.

This repository contains release downloads and the signed update feed only. Application source and personal designs are not published here.

The first signed and notarized release is still being prepared. There is currently no installer to download.

When available, download the latest release ZIP, extract Copperline.app and move it into Applications. Installed release builds offer Copperline → Check for Updates… and optional automatic checks. New releases are published deliberately, not on every code change.

Requirements: Apple silicon Mac; macOS 14 or later is the declared minimum, with additional OS-version testing still pending.
