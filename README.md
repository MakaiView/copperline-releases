# Copperline downloads

Copperline is a macOS app for decorative copper name artwork, by Makai View.

This repository contains release downloads and the signed update feed only. Application source and personal designs are not published here.

## Install

1. Open the [latest release](https://github.com/MakaiView/copperline-releases/releases/latest) and download `Copperline-<version>.zip`.
2. Open the ZIP, then drag **Copperline** into **Applications** and open it from there.

The app is signed with a Developer ID and notarized by Apple, so it opens without a security override.

Requirements: an Apple silicon Mac; macOS 14 or later is the declared minimum, with testing so far on macOS 27.

## Updates

Copperline ▸ **Check for Updates…** installs a newer release when you choose, and **Automatically Check for Updates** turns background checks on or off. Updates are signed and are never installed without your approval; if a project has unsaved changes, Copperline asks first. New releases are published deliberately, not on every code change.
